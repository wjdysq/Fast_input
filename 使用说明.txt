========================================
  剪贴板自动粘贴 —— 使用说明
========================================

【最快上手】
双击  启动.bat  →  看到界面后：
   1. 在任意地方 Ctrl+C 复制一段文字
   2. 用鼠标点进你要粘贴的目标窗口（比如记事本、聊天框）
   3. 按 Ctrl + Alt + V
   → 内容自动输入进去了

不用热键的版本：双击  启动-自动模式.bat
   → 复制后等 2 秒自动输入，你趁这 2 秒切到目标窗口。


【运行时的界面】
启动后会看到一个实时面板（黑底彩字），分四块：

   ┌ 顶部：标题 + 当前状态（监听中 / 正在输入…）
   │ 状态：已捕获几条、等待哪个热键
   │ 目标：前台窗口 / 指定窗口
   │ 手法：逐字键入 200 字符/秒
   ├ 中间：统计（已捕获 / 已输入 / 字符数 / 失败 / 平均速度）
   ├ 日志：带时间戳的滚动记录，最近的事件在上面
   └ 底部：逐字输入时显示进度条

面板宽度会跟着你的窗口自动调整，不会错位。
如果你的终端不支持彩色/框线，会自动降级成带颜色的纯文字；
想彻底关掉面板、只看朴素日志，加 --plain 参数。


【多行文本 / 换行】
复制多行文字（比如一段代码、一封邮件）时，换行会被正确还原，
不会挤成一行。程序会把 Windows 的 \r\n 和旧式 \r 统一成换行，
逐字输入时用真正的回车键动作输入换行，所以行与行会分开。
制表符（Tab）同样会正确跳格。


【两种输入方式】
默认是「逐字快速输入」：内容会一个字符一个字符地打进去，
你能看到输入过程，是"连续快速键入"而不是"啪一下全出现"。

  · 想更直观地看逐字效果 → 双击  启动-逐字输入.bat  （200 字符/秒）
  · 想要瞬间粘贴        → 双击  启动.bat  后改用 Ctrl+V 方式，
                           或命令行加 --method paste

逐字输入的速度可以调：
  --speed 300        每秒 300 个字符（更快）
  --speed 50         每秒 50 个字符（明显能看出在打字）
  --type-interval 0  不限速，尽可能快


【先自检】
双击  自检.bat
   → 会逐项检查本机是否都正常。
   → 重点看第 [8b] 项「逐字键入编码」和第 [9] 项「真实按键注入」。
     第 8b 项验证的是"内容完整、顺序正确"（含中文和 emoji），
     这一项不需要特殊权限，正常都能过。
     第 9 项如果失败，通常是：
       · 目标程序以管理员身份运行，而本程序不是
       · 被杀毒/安全软件拦截了合成按键
       · 在远程桌面或受限会话里


【几个 bat 的区别】

  启动.bat            手动热键模式，逐字输入（推荐）
                      复制后按 Ctrl+Alt+V 才输入，最可控

  启动-逐字输入.bat    同样是热键，但明确用 200 字符/秒逐字键入

  启动-自动模式.bat    复制后延迟 2 秒自动输入
                      省事，但要抓紧时间切窗口

  自检.bat            检查环境是否正常


【常用命令行参数】
在文件夹地址栏输入 cmd 回车，然后：

  python main.py --list-windows          列出所有窗口标题
                                          （配合下面的"指定窗口"用）

  python main.py --target title --title "记事本"
                                          固定输入到标题含"记事本"的窗口

  python main.py --speed 300             调快逐字输入速度

  python main.py --method paste          改回瞬间粘贴（Ctrl+V）

  python main.py --hotkey ctrl+shift+p   换一个热键

  python main.py --dry-run               只看日志，不真的输入（调试用）

  python main.py --plain                 关掉实时面板，用朴素日志输出

  python main.py --init-config           生成配置文件


【配置文件在哪】
   C:\Users\31546\.clip_autopaste.json

   改完保存，重新启动程序即可生效。
   几个有用的项：
     "paste_method": "type"
        → "type" = 逐字快速输入（默认）
        → "paste" = Ctrl+V 瞬间粘贴
     "type_interval": 0.005
        → 逐字输入间隔（秒/字符）。0.005 = 200 字符/秒
        → 填 0 = 不限速
     "exclude_titles": ["密码", "Password"]
        → 命中这些标题的窗口绝不输入（防打进密码框，建议留着）
     "max_text_length": 5000
        → 超过这个长度不输入，防止误复制大段内容


【退出程序】
   在黑色窗口里按  Ctrl + C


【注意】
   · 这台电脑上装了 PixPin（截图工具），它会一直占用剪贴板。
     程序已经做了重试和校验来应对，但如果偶尔没输进去，再按一次热键即可。
   · 如果热键按了没反应，试试按住 Ctrl+Alt 再按 V，多按一下。
   · 逐字输入时请不要动鼠标键盘，否则可能打断输入。
     想中途停下，按 Ctrl+C 关掉程序窗口即可（已输入的部分会留下）。
   · 如果目标程序输入特别慢、还是丢字，可以调慢一点：
     命令行加 --speed 100（每秒 100 字符），程序自己也会自适应降速。
